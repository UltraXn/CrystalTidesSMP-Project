# 🚀 Cohere MCP Server (Model Context Protocol)

Servidor MCP oficial para integrar llamadas a la API de Cohere (Rerank, Embeddings y Chat Command R+).

## 🛠️ Herramientas expuestas

1. `cohere_rerank`: Re-ordena candidatos por relevancia semántica usando Cohere Rerank API (v3.5).
2. `cohere_embed`: Genera embeddings vectoriales semánticos usando Cohere Embed API (v3.0).
3. `cohere_chat`: Chat y completados con Cohere Command R+.

## 🚀 Cómo ejecutar

```bash
cd mcp-servers/cohere-mcp-server
npm install
npm run build
npm start
```
