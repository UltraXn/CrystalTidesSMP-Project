# Migraciones de Base de Datos - Minecraft (MySQL)

Este directorio contiene las migraciones para la base de datos MySQL utilizada por el servidor de Minecraft y el bridge web (`linked_accounts`, stats, etc.).

> **ADVERTENCIA:** Estas migraciones corresponden al motor **MySQL 8** del servidor de Minecraft. **NO** son migraciones de Supabase (PostgreSQL), las cuales residen en `database/web-server/migrations/`.
